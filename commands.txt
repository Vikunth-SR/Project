# Git Commands

1. Initialize new repository

git init

2. clone a repository

  git clone <repo url>

3. check status

  git status

4. add all modifications to stage  

  git add .

  git add command.md

5. commit all changes to local git repo

 git commit -m"some info"

6. push all local changes to live git

git push origin <branch name>

7. combine histories together

git merge <branch-name-to-bring-in>

8. Updates and merge them locally

git pull origin <branch name>

9. Temporarily shelves uncommitted work

git stash

10. reviews commit histories

git log

11. switch between branches

git switch <branch name>

12. Manages and lists text branches

git branches

13. To create new branch

git checkout

14. To delete a branch

git branch -d"Branch name>
