# Git Commands

0. Initialize new repository

git init

1. clone a repository

  git clone <repo url>

2. check status

  git status

3. add all modifications to stage  

  git add .

  git add command.md

4. commit all changes to local git repo

 git commit -m"some info"

5. push all local changes to live git

git push origin <branch name>

6. combine histories together

git merge <branch-name-to-bring-in>

7. Updates and merge them locally

git pull oringin <branch name>

8. Temporarily shelves uncommited work

git stash

9.reviwes commit histories

git log

10. switch between branches

git switch <branch name>

11. Manages and lists text branches

git branches
